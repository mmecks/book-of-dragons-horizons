# Book of Dragons: Horizons

A Minecraft 1.21.1 (NeoForge) modpack built around [Book of Dragons](https://modrinth.com/mod/book-of-dragons) by MrMagister.

## ⬇️ [Download the pack here](https://github.com/mmecks/book-of-dragons-horizons/releases/latest)

get an `.mrpack` file from the latest release and import it into **Prism Launcher** or **Modrinth App**. it won't work in the CurseForge app. pack has been submitted to Modrinth and is waiting for approval.

## Found a bug?

Open an issue in the **Issues** tab, please don't report pack problems to the individual mod authors.

Include:
- pack version (regular or OpenCL)
- launcher (Modrinth App, Prism, ...)
- what happened and how to recreate it
- `logs/latest.log` or crash report (drag the file into the issue)
