# Book of Dragons: Horizons

A Minecraft 1.21.1 (NeoForge) modpack built around [Book of Dragons](https://modrinth.com/mod/book-of-dragons) by MrMagister. Download it on Modrinth.

## Found a bug?

Open an issue in the **Issues** tab, and please don't report pack problems to the individual mod authors.

Include:
- Pack version (regular or OpenCL)
- Launcher (Modrinth App, Prism, ...)
- What happened and how to make it happen again
- Your `logs/latest.log` or crash report (drag the file into the issue)
